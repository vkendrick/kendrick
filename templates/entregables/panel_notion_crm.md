## Cómo usar este panel

Este panel tiene 4 secciones principales. Dedica **15 minutos cada semana** (por ejemplo, los lunes por la mañana) a actualizarlo.

---

## 📊 Sección 1: Resumen Semanal

Actualiza estos números cada lunes:

| Métrica | Esta semana | Semana anterior | Objetivo mensual |
|---|---|---|---|
| Consultas recibidas | | | |
| Presupuestos enviados | | | |
| Clientes nuevos | | | |
| Facturación | | | |
| Reseñas nuevas en Google | | | |

---

## 👥 Sección 2: Pipeline de Clientes (Kanban)

Mueve cada cliente potencial entre estas columnas según su estado:

**NUEVO CONTACTO** → **EN CONVERSACIÓN** → **PRESUPUESTO ENVIADO** → **CLIENTE** → **PROYECTO TERMINADO**

Para cada contacto, registra:
- Nombre y empresa
- Canal de origen (Google, Instagram, recomendación, etc.)
- Fecha de primer contacto
- Servicio de interés
- Notas de la conversación
- Próxima acción y fecha

---

## 📅 Sección 3: Tareas de la Semana

Lista de tareas pendientes. Prioridades:

🔴 **Urgente** — Responder consultas pendientes (máximo 2 horas)
🟡 **Esta semana** — Enviar presupuestos, hacer seguimiento
🟢 **Cuando puedas** — Publicar en redes, actualizar web

---

## 📈 Sección 4: Métricas Mensuales

Al final de cada mes, registra:

| Mes | Consultas | Clientes | Facturación | Coste por cliente | Canal #1 |
|---|---|---|---|---|---|
| Enero | | | | | |
| Febrero | | | | | |
| Marzo | | | | | |

**Cómo calcular el coste por cliente:**
> Dinero invertido en publicidad ese mes ÷ Número de clientes nuevos = Coste por cliente

---

## 🔧 Configuración inicial (solo la primera vez)

1. Duplica esta plantilla en tu Notion personal
2. Rellena la sección de "Resumen Semanal" con los datos actuales de tu negocio
3. Añade todos tus contactos actuales en el Pipeline
4. Pon un recordatorio en tu calendario para los lunes: "15 min — Actualizar Notion"
